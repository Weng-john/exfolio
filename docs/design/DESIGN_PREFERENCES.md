# 設計偏好（全域）

最後更新：2026-11-16。來源：Exfolio 改版的偏好訪談。

## 明確確認

- 先看結論，點進去才看細節。
- 中性極簡的結構：黑白灰、細邊框、KPI 卡帶一句解讀。
- 深色模式低彩度、安靜，數字是主角。
- 對比不要太強烈（高彩度紅綠熱圖要降彩度）。
- 標題帶襯線感；中文標題可用明體。
- 願意有少量動畫。
- 回覆用繁體中文；區分查證事實與推論；時效性資訊附來源。

## 推論（不是規則，下次要再確認）

- 偏好工具感勝過行銷感。
- 喜歡 Apple 系的霧面玻璃材質。

## 專案決定（不自動套用到其他專案）

- 見各專案的 `DESIGN_DECISIONS.md`。Exfolio：深藍灰強調色、上導覽加左次導覽、手機漂浮分頁列、損益顏色可切換。
