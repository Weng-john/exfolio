# 設計文件

| 文件 | 範圍 | 內容 | 何時更新 |
|---|---|---|---|
| `UIUX_SKILL.md` | 全域（暫放此處） | 設計研究流程、提問規則、檢查清單 | 流程改變時 |
| `DESIGN_PREFERENCES.md` | 全域（暫放此處） | 擁有者跨專案的設計偏好，分確認、推論、未確認 | 每次提案獲准後，經擁有者同意才寫入 |
| `DESIGN_PROFILE.md` | Exfolio | 產品、使用者、核准的方向、設計變數、元件規範 | 方向或變數改變時 |
| `UIUX_AUDIT.md` | Exfolio | 稽核結果與量測 | 每次稽核 |
| `UIUX_REDESIGN_PLAN.md` | Exfolio | 改版提案與實作路線圖、進度 | 計畫或進度變動時 |
| `DESIGN_DECISIONS.md` | Exfolio | 設計決策紀錄 | 每個重要決定 |

兩份全域文件不屬於單一專案；擁有者指定其他位置前先放在這裡，其他專案引用時複製，不要在別的專案裡直接改。
