# Exfolio 設計檔案

最後更新：2026-11-16。決策脈絡見 `DESIGN_DECISIONS.md`。

## 產品與使用者

以 NAV 為分母、用曝險看全貌的個人資產配置工具。使用者是會用槓桿 ETF、期貨、質押借款的進階個人投資者；公開版另有不登入試算的訪客。訪客與會員同一套設計。

## 方向

「安靜的專業工具」：打開先看到結論，需要時才展開細節。中性黑白灰加深藍灰強調色；深色模式低彩度；標題用襯線；金額用等寬數字。

參考：shadcn/ui Dashboard（KPI 卡、圖表切換）、Ghostfolio（導覽型態、總覽只回答一個問題）、Mercury（深色氣質、襯線、大數字）、OptionStrat（損益表，降彩度）、Sharesight（圖表篩選列）。

## 設計變數

| 用途 | 淺色 | 深色 |
|---|---|---|
| 頁面底 / 卡片 | `#fafafa` / `#ffffff` | `#14161b` / `#1b1e25` |
| 邊框 / 柔和底 | `#e4e6ea` / `#f1f3f6` | `#2a2e37` / `#232730` |
| 主文字 / 次文字 | `#111827` / `#667085` | `#e8eaee` / `#98a0ad` |
| 強調色 | `#1e293b` | `#cbd5e1` |
| 正 / 負 | `#2f7d5b` / `#b4534a` | `#7fbf9f` / `#d98b82` |
| 標記（目標、現價） | `#b7791f` | `#d9b46a` |

這些是提案值；實作以 `src/web/styles.css` 為準，且每個文字色都要通過 axe 的 4.5:1。

- 損益顏色是設定：預設綠正紅負，可切換紅漲綠跌。只交換正、負兩個語意變數。
- 字級七級：40（NAV）、30（頁標題）、18（卡片標題）、22（KPI）、14（內文）、12–13（輔助）、11（徽章、損益表格子）。
- 字體：標題的拉丁字與數字用襯線，中文用明體（自架、分片載入）；內文與表格用黑體。金額等寬數字，小數縮小。
- 間距 4 的倍數；內容最大寬度 1280；卡片間距 12。
- 圓角：卡片 10、按鈕與輸入 8、膠囊 999。卡片只用邊框；陰影只給浮層。

## 元件規範

- 按鈕：主要（強調色實心）、次要（邊框）、文字。每個區塊最多一個主要按鈕。
- KPI 卡：標籤、數字、一句解讀。一排最多 4 張。
- 表格：數字靠右、等寬；長表每頁 25 列；手機改成每列一張卡。
- 表單：標籤在上、提示在下、錯誤在欄位旁。
- 狀態：載入用骨架；空狀態一句說明加一個主要按鈕；好消息型空狀態一行確認列；成功用右下角通知。

## 導覽

上方主導覽五區，左側是該區的次導覽；手機是底部漂浮分頁列（霧面半透明，降低透明度時改實心）。網址不變。

| 主導覽 | 頁面 |
|---|---|
| 總覽 | 投資總覽 |
| 配置 | 核心配置、新資金配置 |
| 帳務 | 帳戶與持倉、借款與質押、期貨與轉倉 |
| 分析 | 風險實驗室、選擇權實驗室（完整版另有主動策略、交易日誌、績效分析） |
| 設定 | 設定與資料（會員另有我的帳號、會員管理） |

## UX 原則

- 先結論、後細節：頁首一排結論卡，明細收合或分頁。
- 長清單預設只顯示有持倉、有資料的項目，並提供「顯示全部」。
- 資訊不只靠顏色：損益要有正負號。
- 動效少量：切換淡入、數字滾動、圖表進場一次；遵循減少動態效果。
- 不強制任何槓桿上限；所有建議只供參考（產品規則，不因改版而變）。
